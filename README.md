# 🏰 Console Math Quest (Консольная математическая игра)

Консольная игра-квест на языке Java. Главному герою (рыцарю) необходимо добраться до замка, преодолевая препятствия в виде монстров. Чтобы пройти мимо монстра или убить его, игроку нужно решить математический пример.

## 🚀 Основные возможности
* **Разные типы монстров:**
    * 🧟 Зомби (дают простые примеры на сложение и умножение).
    * 🧛 Вампиры (дают сложные примеры с корнями и логарифмами, сложность зависит от уровня игры).
    * 🛡️ Стражи замка (имеют два щита — чтобы убить, нужно решить два задания подряд).
* **Механика ключа:** Замок заперт! Чтобы пройти игру, нужно убить случайного монстра и забрать у него ключ 🗝️.
* **Туман войны:** Опциональная механика, скрывающая часть карты и заставляющая игрока исследовать поле.
* **Режим Custom:** Возможность настроить размер поля, количество монстров, сложность и даже иконки персонажей.
* **Система жизней:** При неправильном ответе игрок теряет жизнь. При 0 жизней дается один "второй шанс".

## 🛠️ Технологии
* **Язык:** Java 19
* **Среда разработки:** IntelliJ IDEA
* **Сторонние библиотеки:** Не используются (только стандартная библиотека Java SE).

## 🎮 Как играть
1. Запустите класс `Main` (файл `Main.java`).
2. В консоли введите `ГОТОВ` (или `HELP`, чтобы прочитать правила).
3. Выберите сложность: `easy`, `medium`, `hard` или `custom`.
4. Выберите опциональную возможность (Туман войны) — введите Да или Нет.
5. Управление происходит путем ввода координат `x y` (через пробел).
    * Ось X идет слева направо.
    * Ось Y идет сверху вниз.
    * Ходить можно только на 1 клетку вверх, вниз, влево или вправо (по диагонали нельзя).
6. Ваша цель — найти ключ и добраться до замка 🏰.
